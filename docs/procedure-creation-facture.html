إجراء إنشاء الفاتورة

Service Time — دليل مختصر

الفاتورة وثيقة مالية رسمية لمبلغ الطلب. تُنشأ تلقائياً في النظام ثم تؤكدها الإدارة قبل ظهورها للعميل.

  1. 1) إنشاء الطلب يرسل العميل طلب صيانة أو طلب قطع غيار عبر المنصة.
  2. 2) إنشاء الفاتورة تلقائياً تُنشأ الفاتورة عند انتقال طلب الصيانة إلى «قيد التنفيذ»، أو عند تأكيد طلب قطع الغيار.
  3. 3) مراجعة الإدارة يراجع المسؤول المبلغ، بيانات العميل، وتفاصيل الخدمة أو المنتجات.
  4. 4) تأكيد الفاتورة بعد التأكيد تصبح الفاتورة ظاهرة للعميل في حسابه.
  5. 5) عرض وتحميل PDF يمكن للعميل الاطلاع على الفاتورة وتحميلها بصيغة PDF.

ملاحظة: العميل لا يرى الفاتورة قبل تأكيد الإدارة.
